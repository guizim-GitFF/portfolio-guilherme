## 💻 Sobre o Projeto do Portfólio

O site foi desenvolvido para apresentar minha jornada acadêmica e metas de carreira com uma identidade visual inspirada em desenhos técnicos (**Blueprint / CAD**) e engenharia industrial[cite: 5].

### ✨ Funcionalidades Principais
* **Design Responsivo:** Adaptado para computadores, tablets e smartphones[cite: 5].
* **Alternância de Tema:** Modo Escuro (*Blueprint*) e Modo Claro (*Oficina Técnica*)[cite: 5].
* **Roadmap Interativo:** Filtro de objetivos profissionais divididos em curto, médio e longo prazo[cite: 5].
* **Simulador Mecânico (JavaScript):** Calculadora interativa de potência mecânica ($kW$ e $cv$) a partir do Torque ($N\cdot m$) e Rotação ($RPM$), com animação de engrenagens sincronizada em tempo real[cite: 5].
