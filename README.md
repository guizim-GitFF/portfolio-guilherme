# Portfólio Pessoal — Guilherme (Rumo à Engenharia Mecânica)

Projeto desenvolvido para a disciplina de Desenvolvimento de Sistemas, apresentando minha trajetória acadêmica, habilidades e meu objetivo profissional na **Engenharia Mecânica**.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3 / Tailwind CSS** (Estilização responsiva com tema Blueprint/Industrial)
- **JavaScript** (Alternância de tema claro/escuro, filtro de objetivos e simulador de potência mecânica)

## 🌐 Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Vá em **Settings > Pages**, selecione a branch `main` e clique em **Save**.
